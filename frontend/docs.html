DAU Buddy Server

An MCP platform providing AI assistants with structured access to DA-IICT faculty, staff, library, timetable, academic calendar, and scholars data through PostgreSQL-backed retrieval services.

Features

  • Faculty Tools: List faculty, search by name or expertise, view full profiles, and trigger live website syncing.
  • Staff Tools: List staff, search by name or designation, view full profiles, and trigger live website syncing.
  • Scholars Tools: List Ph.D. scholars, search by name or research area, view detailed profiles.
  • Library OPAC Tools: Instantly search the DA-IICT library catalog (over 28,000 records) and retrieve detailed book metadata using PostgreSQL full-text search.
  • Timetable Tools: Query faculty schedules, course timings, free time slots, and full program batch timetables.
  • Calendar Tools: Query academic calendar events, examination schedules, semester activities, and holidays.
  • Secure Authentication: All endpoints are secured by an ASGI authentication middleware that verifies API keys.

Editor Configurations

Copy the configurations directly from your web dashboard to ensure your API keys are correctly injected.

1. Claude Desktop (HTTP/SSE via Proxy)

Claude Desktop connects to our HTTP/SSE server using a local npx mcp-remote bridge to securely pass the Server-Sent Events stream into Claude's memory.

{
  "mcpServers": {
    "DAU Buddy": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "http://127.0.0.1:8001/mcp/sse",
        "--allow-http",
        "--transport",
        "sse-only",
        "--header",
        "Authorization:${AUTH_HEADER}"
      ],
      "env": {
        "AUTH_HEADER": "Bearer <YOUR_API_KEY>"
      }
    }
  }
}

2. Cursor / Windsurf (Native HTTP/SSE)

Cursor and Windsurf support direct SSE network connections. You only need to supply the connection URL, the explicit type flag, and your API key header:

{
  "mcpServers": {
    "DAU Buddy": {
      "type": "sse",
      "url": "http://127.0.0.1:8001/mcp/sse",
      "headers": {
        "Authorization": "Bearer <YOUR_API_KEY>"
      }
    }
  }
}

3. OpenCode (Remote HTTP/SSE)

OpenCode connects using the remote type flag:

{
  "mcpServers": {
    "DAU Buddy": {
      "type": "remote",
      "url": "http://127.0.0.1:8001/mcp/sse",
      "headers": {
        "Authorization": "Bearer <YOUR_API_KEY>"
      }
    }
  }
}

Available Tools & Queries

Faculty

list_faculty(), search_faculty(query), get_faculty_details(name_or_email)

Example: "Who is the faculty expert in Machine Learning?"
Staff

list_staff(), search_staff(query), get_staff_details(name_or_email)

Example: "Who is the placement coordinator?"
Scholars

list_scholars(), search_scholars(query), get_scholar_details(name)

Example: "Find Ph.D. scholars researching Machine Learning."
Library

search_library_books(query, limit), get_book_details(biblionumber)

Example: "Find books on Artificial Intelligence."
Timetables

get_faculty_schedule(name, day), find_faculty_free_time(name, day), get_program_timetable(program, day)

Example: "When is Prof. Manish Khare free on Tuesday?"
Calendar

get_next_holiday(), get_midsem_dates(), search_calendar(query, semester)

Example: "When are the mid-semester exams?"
