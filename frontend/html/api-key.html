Integration Configuration

Add this to %APPDATA%\Claude\claude_desktop_config.json. It connects entirely over the network via a memory-loaded proxy, with no local file paths or environment variables exposed.

Node.js Required: You must have Node.js installed on your PC to use this Claude Desktop configuration. 
{
  "mcpServers": {
    "DAU Buddy": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "http://127.0.0.1:8001/mcp/sse",
        "--allow-http",
        "--transport",
        "sse-only",
        "--header",
        "Authorization:${AUTH_HEADER}",
        "--header",
        "X-Client-Name:Claude"
      ],
      "env": {
        "AUTH_HEADER": "Bearer "
      }
    }
  }
}

Add this block to your Cursor, Windsurf, or OpenCode MCP settings to connect over the network using Server-Sent Events (SSE). Requires the backend server to be running. 

{
  "mcpServers": {
    "DAU Buddy": {
      "type": "sse",
      "url": "http://127.0.0.1:8001/mcp/sse",
      "headers": {
        "Authorization": "Bearer ",
        "X-Client-Name": "Cursor/Windsurf"
      }
    }
  }
}

Add this block to your OpenCode MCP settings to connect over the network using Server-Sent Events (SSE). Requires the backend server to be running. 

{
  "mcpServers": {
    "DAU Buddy": {
      "type": "remote",
      "url": "http://127.0.0.1:8001/mcp/sse",
      "headers": {
        "Authorization": "Bearer ",
        "X-Client-Name": "OpenCode"
      }
    }
  }
}
