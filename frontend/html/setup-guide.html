Connect Your IDE to DAU Buddy MCP Server

Follow these step-by-step instructions to integrate our MCP server with your favorite AI-powered coding tools.

Connecting to Claude Desktop

1

Open Claude Configuration

Open Claude Desktop, go to Settings > Developer, and click Edit Config.

2

Add the MCP Server Settings

This will open your claude_desktop_config.json file. Next, go to your API Keys Dashboard to create an API key.

Copy the configuration settings and replace <YOUR_API_KEY> with your new key. Keep your API key safe! It is shown only once. If you forget it, you will need to regenerate it and update this file again.

3

Restart Claude

Force quit Claude (make sure to also quit it from your background processes/system tray) and then start Claude again.

You will see DAU Buddy running in the Developer options. You can now start asking questions to DAU Buddy!

Connecting to Cursor IDE

1

Open Cursor Settings

Open Cursor and go to Settings. In the settings, find the option for Tools & MCPs and navigate to it.

2

Add Custom MCP Server

Click on + Add New MCP Server (or Add Custom MCP Server). This will open your mcp.json file.

Next, go to your API Keys Dashboard to create a new API key. Copy the configuration settings below and paste them into the file.

Keep your API key safe! It is shown only once. If you forget it, you will need to regenerate it and repeat this setup.

3

Refresh Tools

Just click the Refresh button located above the "Add New MCP Server" option to apply your new configuration and connect DAU Buddy.

Connecting to Opencode

1

Ask AI to Setup MCP Server

Open Opencode and simply tell the AI to "setup MCP server" for you.

2

Paste the Configuration

Go to your API Keys Dashboard to create an API key, then copy the configuration settings provided there.

Paste these configs when the AI prompts you. Keep your API key safe! It is shown only once. If you forget it, you will need to regenerate it and do this setup again (changing API keys, etc.).

3

Restart Opencode

Just close Opencode and open it again for the changes to take effect!

Connecting to Codex

1

Open Configuration

Open ChatGPT, click on your profile and go to Settings. You will find the Configuration option; click on that and open config.toml.

2

Add API Key Settings

After opening the config file, go to your API Keys Dashboard and create an API key. Copy the configuration settings and paste them in.

Keep your API key safe! It is shown only once. If you forget it, you will need to regenerate it and repeat this setup.

3

Ask Questions

Just ask a question, and it will now give you answers directly from DAU Buddy!
