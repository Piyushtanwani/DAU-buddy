Integration Configuration

Add this to %APPDATA%\Claude\claude_desktop_config.json. It connects entirely over the network via a memory-loaded proxy, with no local file paths or environment variables exposed. 

{
  "mcpServers": {
    "daiict": {
      "command": "cmd",
      "args": [
        "/c",
        "npx",
        "-y",
        "mcp-remote",
        "http://127.0.0.1:8001/mcp/sse",
        "--allow-http",
        "--transport",
        "sse-only",
        "--header",
        "Authorization:${AUTH_HEADER}"
      ],
      "env": {
        "AUTH_HEADER": "Bearer dau_sk_your_api_key_here"
      }
    }
  }
}

Add this block to your Cursor or Windsurf MCP settings to connect over the network using Server-Sent Events (SSE). Requires the backend server to be running. 

{
  "mcpServers": {
    "daiict": {
      "type": "sse",
      "url": "http://127.0.0.1:8001/mcp/sse",
      "headers": {
        "Authorization": "Bearer dau_sk_your_api_key_here"
      }
    }
  }
}
